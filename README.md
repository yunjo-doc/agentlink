# agentlink

AI 에이전트 기반 소셜 미디어 통합 발행 서비스의 웹 프로토타입입니다. 웹 기획서(가격·결제 제외)를 바탕으로 만들었습니다.

## 실행

Node.js 18 이상이 필요하고, 설치할 패키지는 없습니다.

```bash
ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD='8자이상비밀번호' SESSION_SECRET='긴임의문자열' npm start
# http://localhost:3000
```

## 회원 가입과 관리자 승인

- 누구나 바로 가입할 수는 없습니다. 사용자는 `가입 신청`을 보내고, 관리자가 승인해야 로그인할 수 있습니다.
- 관리자는 환경 변수 `ADMIN_EMAIL` / `ADMIN_PASSWORD`로 지정합니다. 서버가 시작될 때 이 값으로 관리자 계정을 만들거나 비밀번호를 갱신합니다.
- 관리자로 로그인한 뒤 **대시보드 → 회원 관리**에서 신청을 승인·거절하고, 회원을 비활성화하거나 삭제합니다. 비활성화하면 그 회원의 로그인도 즉시 끊깁니다.

| 환경 변수 | 설명 |
| --- | --- |
| `ADMIN_EMAIL` | 관리자 이메일 |
| `ADMIN_PASSWORD` | 관리자 비밀번호 (8자 이상) |
| `SESSION_SECRET` | 로그인 세션 서명 키. 없으면 서버가 재시작될 때마다 모두 로그아웃됩니다. |
| `DATA_DIR` | 회원 데이터(`users.json`) 저장 폴더. 기본값은 `./data`입니다. |

> 회원 데이터는 서버 디스크의 JSON 파일에 저장됩니다. Render 무료 Web Service처럼 디스크가 유지되지 않는 환경에서는 재배포·재시작 시 가입 신청과 회원 목록이 사라집니다. 유지하려면 영구 디스크를 붙이고 `DATA_DIR`을 그 경로로 지정하세요.

## 구성

| 경로 | 내용 |
| --- | --- |
| `server.js` | 정적 파일 제공 + 가입 신청·로그인·관리자 승인 API |
| `index.html` | 진입점 (해시 라우팅 SPA) |
| `css/style.css` | 스타일, 다크 모드, 반응형 |
| `js/data.js` | 채널·에이전트·기능 상태·오류 코드의 단일 관리 원천과 채널 규격 검증 |
| `js/core.js` | 다국어(KO/EN), 라우터, API 호출, 헤더·푸터, 모달·토스트 |
| `js/pages-public.js` | 홈, 에이전트 연결, 지원 채널, 비교, 블로그, 법무 |
| `js/pages-docs.js` | 문서, API 레퍼런스, 채널별 안내 |
| `js/dashboard.js` | 로그인, 가입 신청, 대시보드(발행, 기록, 소셜 계정, MCP, API 키, 설정, 회원 관리) |

## 참고

- 로그인과 회원 관리는 실제로 동작합니다. 소셜 계정 연결·OAuth·게시는 시뮬레이션이며, 그 시연 데이터는 회원별로 브라우저 localStorage에 저장됩니다.
- `js/data.js`의 채널 수치와 기능 상태는 기획용 기본값이므로 실제 제품과 대조해 확정해야 합니다.
- MCP 서버 주소와 API 주소는 예시 값입니다.
